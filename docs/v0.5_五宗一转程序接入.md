# v0.5 五宗一转框架（程序 #12）

职业登记在 `src/config/classes.json`；五个职业 id 为 `tianjian_disciple`、`taixu_acolyte`、`lingfu_novice`、`youying_shadow`、`wanshou_tamer`。职业的宗门及一转编号由登记表读取，技能树按共享 `skills.json` 的 `sect/job` 生成，功法窗口和快捷栏只显示本宗技能。

## 配表字段

- `skills.rules`：`spPerLevel/jobAdvanceBonusSp/masteryCapBonus/budget.jobN.levels`；技能：`id/name/sect/job/type/maxLevel/spCost/masteryPerHit/masteryToCap/mpCost/cooldownMs/damageRatio/hitCount/maxTargets/range/durationMs/perLevel/effects/req/fx/icon/key`。
- `quests`：`giver/turnIn/reqLevel/prereq/phase/objectives.trial/rewards.job/rewards.skills/rewards.items`；`npcs`：`quests/map`。新玩家赠技只读取 `rewards.skills`；技能树补齐仅用于兼容旧职业存档。
- `items`：`slot/sect/reqLevel/appearance/stats`；`player_growth.statEffects` 换算被动神识、根骨等属性。友方灵狼读 `monsters.spirit_wolf.sprite/tint`，模板缺失仍回退 `mon_wild_wolf`；HP、DEF、持续时间、数量、跟随/攻击参数读技能 `effects/perLevel`。
- 转正美术通过原有 sync 素材清单加载，跳过 `_pending`；功法窗图标依次退回 64px、32px 图集和占位，快捷栏用 32px 图集或占位，缺特效用代码占位，功法被动不施放、不生成特效。

## 行为与兼容

新角色交付 `q_breakthrough` 获得 `spirit_bolt` Lv1，交付 `q_fox` 按表获得五宗帖及物品，不定职、不再赠送回风剑和轻身术。正式交付 `q_sect_*` 才定宗并按表赠技，天剑宗为剑气斩、回风剑、轻身术；穿上奖励的本宗道袍，旧衣进背包。拜入时移除灵气弹，仅退回付费等级的点数，赠送等级不返点；原灵气弹热键换成本宗入门技，保留其他本宗键位，禁止重复拜入其他宗门。未拜宗角色保留原剑修技能窗口及战斗行为。

存档新增 `questRewardVersion: 1`，新角色以及读取后的旧档均保存该标记。缺标记的旧档若已交付 `q_fox` 且没有已有职业或正式拜入记录，迁成天剑宗剑徒；已有正式记录优先。旧剑徒自动登记职业版本和奖励收据，保留等级、技能等级、熟练度、点数、快捷栏、当前装备；补道袍进背包，刷新不重复发奖。旧档尚未交付妖狐时只升级标记，之后交付按新表发奖，不触发旧剑徒迁移。已完成正式拜入任务的档自动补职业。

独立冷却按绝对时间保存，切图/刷新仍保留剩余冷却；剑修无独立冷却的原后摇行为不改。

调试使用 `?debug=class=<职业id>`，默认进入本宗山门；山门尚未供图时按拜入任务关联的试炼表进入本宗试炼图，也可加 `&map=<地图id>`。创建独立 Lv29 角色，五项技能 Lv1，主动/增益按树顺序绑定 A/S/D，灵力回满；调试角色不写真实存档，换图保持。

## 接口与缺口

- 共享表缺职业登记及正式拜入任务的 `rewards.job`，拜入任务未挂接引人/长老 `quests`。程序登记映射、按任务 giver/turnIn 补 NPC 入口；新玩家技能和物品奖励直接读取任务表，未编辑 balance JSON。
- 四宗完整试炼胜负控制器仍待后续实现（历史 #12a 已注明胜负与画符输入未完成）：胜利时调用 `QuestSystem.onTrialComplete(trialId)`，或发出 `trial:complete` 携带 trialId。只接取任务、进试炼图或局部机关事件不能通关。未把未实现的宗门日常开放。
- 四宗山门尚未供图，调试入口回退现有本宗试炼图；真实飞舟表目前只配万妖林与天剑宗路线，四宗自然行程仍待地图/航线配表。
- 未实现特殊效果：掌心雷麻痹与首领免疫规则；影遁残影吸引一次仇恨；敌方范围/弹道技能命中灵兽。接口分别为 `SkillCombat.registerSpecialEffect`、`skill:effect`、`receiveSummonDamage`；灵契已接触伤害分担，隐身已接普通寻敌及下一整次攻击必暴。
- 缺基础/成长/武器 `matk` 字段时，职业登记规则显式回退 `atk`，神识法攻仍按 `statEffects` 换算；缺角色灵根元素，保留 `rootElement` 和五行亲和接口，空值没有同元素奖励。
- `talisman_paper` 未登记为物品时暂不扣符纸；登记后自动启用消耗及免耗。四宗缺独立弹速/命中延迟，沿剑气 480px/s、90ms；灵兽受击无敌时间缺字段，暂用 700ms。
- 最终复核五宗一转 25 个 @64 图标和 15 项主动/增益特效均已转正，无缺图；仍保留缺图占位路径，待验收文件不加载。

`npm run test:classes` 包含完整技能树、前置/等级、灵力/冷却、点数/退点/奖励去重、旧剑徒和未拜宗存档、实际属性/伤害计算契约。DPS 枚举覆盖 Lv10–29、0SP、目标防御 0/8/16、熟练上限 +0/+2 和太虚非同元素，共 630 场景；持续单体设计模型与演武堂 08 相同，不计走位/命中/飞行等待，不能解释为五宗实战 DPS 测量。
