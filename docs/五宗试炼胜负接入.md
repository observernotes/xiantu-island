# 五宗拜入试炼接入（#12）

四宗须持有 `five_sect_token`，在背包打开五宗帖并选定本宗后才可接取 `q_sect_*`。选择保存为 `selectedSect`，不消耗帖、不授职业；试炼成功前可重新打开改选。接取后在对应长老处选择「进入试炼」，读取 `trial.enter_confirm` 再开启新一局。接取、入场、胜利登记和交付均复查门槛；不满足门槛的旧 active 档隐藏入场、给出提示，可在接引或长老处放弃回到未接并清除该任务的通关记录。胜利只完成试炼目标，返回长老处交付才正式拜入并沿用职业、退点、赠技和换装逻辑。天剑宗按设计免独立试炼，沿用妖狐前置、传功长老对话交付，本次四宗门槛不改变天剑兼容。

- 太虚：表内全部灯亮后，按间隔刷完并清空三波纸傀儡；点灯超时或倒地失败。
- 灵符：桌前按高亮方向画符，错笔只重画当前道；完成全部符后开始限时木靶挑战，重复靶位使用不同实例 id。
- 幽影：临时授权表内隐息术和影遁，隐息术次数及持续时间读表；发现失败，取令牌后实际回到返回区域才胜利。
- 万兽：山魈按怪物表的半血阈值跪地，地面附近持续按 Z 吹笛；移动、攻击、受伤或松键重置读条；驯服后临时伙伴与玩家清完两波野狼。

失败、Esc 退出或 R 复位均回长老入口；掉出试炼地图判失败。失败不扣修为、灵石或额外道具；玩家主动用药仍按普通背包规则消耗。返回提示分别读取 `trial.fail_return`、`trial.exit_return`。

`completedTrials` 和正式任务状态即时存档，重复通关与交付不重复发奖。`pendingSectTrial` 保存未结算尝试及返回位置，页面刷新按中断返回入口，重新确认后从头挑战。局内令牌、借用技能、增益、冷却和临时快捷栏不写入永久存档；退出恢复原快捷栏。试炼敌人没有经验、掉落或普通任务击杀奖励。

四宗山门尚未注册，`sectEntryMap` 将现有航线落到本宗试炼图入口区，补同一接引人和长老及落霞镇返程入口；入口区不运行目标、不刷试炼敌人。`fiveSectClasses:false` 维持 v0.5b 默认关闭，地图入口同时遵守 `v05Maps`；关闭开关后仍可从旧地图返回。

验证入口：`npm run test:trials`、`npm run test:classes`；无头冒烟先 `npm run build:test`，再 `npm run test:smoke:trials`。生产包用 `npm run build` 校验测试接口未泄漏。`XT_DATA=snapshot|shared` 可以分别验证配表模式。
