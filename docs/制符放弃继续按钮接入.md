# UI-4 制符「放弃/继续」按钮接入

基线 `c8d69f3` 已包含 UI-2。经 `rg` 核实，原仓库没有 `TalismanPanel`、制符正式入口或制符窗按钮；已有灵符技能及试炼不能替代正式制符窗口。本次新增 `src/TalismanPanel.ts` 最小受控窗壳，复用图鉴/炼丹/商店的公共窗体件，只处理按钮皮肤、文案、交互状态和事件。正式玩法入口仍待主程序接入。

## 配置与纹理

`preloadHud` 将 `art/icons/ui/talisman/talisman_ui.json` 加载为 JSON cache key `talisman_ui`。窗壳每次打开或 `setState` 重绘时读取该缓存，未复制素材表到 TypeScript。

| 按钮 | 配置字段 | 图片与切片 |
| --- | --- | --- |
| 开始制符 / 再来 | `detail.buttons.image`、`nineSlice`、`startOrAgain` | `alchemy/ui_alchemy_btn_{normal,hover,pressed,disabled}`；切片从主按钮字段读取 |
| 放弃画符 / 继续画符 | `detail.buttons.abandonOrContinueImage`、`abandonOrContinue` | normal → `hud/ui_hud_dialog_option_normal`；hover/pressed → `hud/ui_hud_dialog_option_selected`；disabled → `hud/ui_hud_dialog_option_disabled` |

次按钮九切片从 **`abandonOrContinueImage.nineSlice`** 读取，当前为 `[6,6,6,6]`，顺序左/右/上/下；不借用 HUD 表或主按钮切片。次按钮文字颜色从同字段的 `textColor.normal/disabled` 读取，当前为 `#3B2A20` / `#8E867C`，缺图时仍保留这些字色。WebGL 使用 Phaser NineSlice；Canvas 使用整图拉伸。

图片引用去掉目录前缀映射到实际 texture key，例如 `hud/ui_hud_dialog_option_normal` → `ui_hud_dialog_option_normal`。主按钮模板按状态展开，继续使用炼丹按钮。

窗口尺寸读 `window.size`，当前为 640×400，居中显示。两个按钮坐标均读表、相对窗口左上角；当前主按钮 `[222,346,112,28]`，次按钮 `[342,346,112,28]`。公共窗体、标题、内框和关闭钮复用 bestiary 素材，内框与关闭坐标也来自缓存。

## 受控接口

```ts
const panel = new TalismanPanel(scene, action => {
  // action: 'start' | 'again' | 'abandon' | 'continue' | 'close'
  // 交给主程序控制器；涉及退出/放弃时先走确认，不在这里直接扣料或结算。
});
panel.open({
  primary: 'start',             // 'start' | 'again'
  secondary: 'abandon',         // 'abandon' | 'continue'
  primaryDisabled: false,
  secondaryDisabled: false,
  message: '',
});
panel.setState({ secondary: 'continue', secondaryDisabled: true });
panel.snapshot();              // open/state/position/artUsed/buttons
panel.close();                 // 由控制器确认可关闭后执行
```

按钮文案优先读取 `talisman.start/again/abandon/continue/title`，缺文案时分别回退「开始制符」「再来」「放弃画符」「继续画符」「制符」，未修改共享 strings/balance/features。

可用按钮依次响应 normal、pointerover → hover、pointerdown → pressed、pointerup → hover 并发一次动作。移出恢复 normal，按下后拖出不触发动作。disabled 没有交互区域；重新启用会重建状态。按钮动作不会自行切换制作阶段。× / Esc 只发 `close` 请求，不自行推断放弃语义。`close()` 销毁窗体和全部按钮；场景 shutdown 同时解绑 Esc。

`snapshot()` 的 `artUsed` 按 texture key 报告每个已创建状态/窗体件的 `art|code`；`buttons` 另报告当前可见状态、背景实际类型/纹理/尺寸/切片、字色、矩形和是否可交互。

## 可选图片与逐件回退

三张 HUD 对话选项图已由 UI-2 的 `preloadHud` 通过 `loadOptionalImage` 加载；炼丹按钮由 `preloadAlchemy`、公共窗体由 `preloadHud` 同样可选加载。本次沿用这些加载入口，不重复加载图片，不改可选资源处理器或共享素材。

构建清单外的图片不入队、不发请求；清单中有但实际文件不存在或不能解码时，既有可选加载错误处理让 Loader 正常完成。窗壳逐状态检查纹理，只有缺的状态退回代码矩形；其他状态继续使用精修件。次按钮代码底板为宣纸/墨褐框，hover/pressed 朱红框，disabled 灰色；主按钮代码底板为朱红/灰。窗体件也逐件回退，关闭图缺失时仍有可点的 ×。

## 主程序仍需提供的接口与逻辑

本次只提供界面件，**需要主程序补正式制符入口与玩法控制器**，没有注册 NPC、快捷键或 features 开关。`TalismanPanel` 当前仅由测试桥实例化；正式接入时应在已经加载 `preloadHud` 和 `preloadAlchemy` 的 UI 场景中创建，并按设计提供：

1. 制符入口、已学配方/等级/境界/材料/容量/非战斗与非试炼等预检结果，驱动按钮 enabled、标签和提示。
2. `start/again` 的一次性扣料、`attemptId` 持久化及当前制作阶段；扣料成功后才进入画符，失败/放弃不退料。
3. `abandon/close` 的二次确认。确认文字参考 `talisman.abandon_confirm`：「放弃本次画符？已用材料不返还。」确认后记 `interrupted`；选择继续时恢复原尝试，不重新扣料。窗壳收到动作并不等于确认。
4. 方向 QTE、暂停/恢复、失焦处理和松键保护；正式独立 UI Scene 的地图/物理/战斗暂停与 modal 输入隔离。本次测试夹具不实现暂停，也不应直接作为正式玩法入口。
5. 完成度、成功率、品质封顶、幂等结算、品质分堆入包/待领取、任务事件及中断恢复；结果按钮不负责发奖。

## 自测

```sh
npm run sync
npx tsc --noEmit
npm run build
npm run test:optional-assets
npm run test:smoke:talisman-ui
```

smoke 沿用 `attr-ui-smoke.mjs` / `dialog-option-smoke.mjs` 的 Playwright、快照构建和可选资源验收方式。独立临时工程和 preview 不覆盖工作树正式 dist，不改变共享素材或开关。默认截图与机器报告在 `/workspace/reports/ui4/`，可通过 `XT_TALISMAN_UI_SHOTS` 改目录；浏览器路径支持 `PLAYWRIGHT_MODULE` / `CHROMIUM_EXECUTABLE_PATH`。

测试桥仅存在于 `VITE_XT_TEST=1`：

```js
__xt.openTalismanPanel({ secondary: 'abandon' });
__xt.setTalismanPanelState({ primary: 'again', secondary: 'continue' });
__xt.setTalismanButtonDisabled(true); // 次按钮
__xt.talismanSnapshot();            // 窗壳快照 + actions 意图记录
```

桥只记录按钮意图，`close` 时收起测试窗；不模拟制符成功或材料结算。覆盖放弃/继续及主按钮四态、读表坐标/独立切片/字色/图片引用、真实鼠标与禁用/恢复/拖出/×/Esc、不改变材料/灵石，以及相关图片清单全部缺失和逐张移走临时 dist PNG。实体缺图保留构建清单，验证 preview 返回 200 HTML 时的静默解码失败，并用 finally 还原文件。每个上下文的原始 console.error、pageerror、requestfailed、HTTP 错误均须为零。正式 `npm run build` 同时跑 leak-check，确保测试桥不进入正式产物。
