# UI-6 加点窗接入

`AttrPanel` 只保存本地增量草稿 `delta`，加减不写档；第一次确认展示分配总数，第二次确认调用 `Progress.applyAllocate(delta)`。确认成功清空草稿，重复点击不会重复提交；保存失败回滚属性与余额并保留草稿。第一版不支持洗点。

| 接口 | 约定 |
| --- | --- |
| `STAT_KEYS` / `statKeys()` | 只读四维：`rootBone/agility/spirit/insight`。 |
| `allocatedStats` / `allocatedStat(k)` | 已确认的非负整数点数；缺键读 0。 |
| `unspentStatPoints` | 尚未分配的非负整数点数。 |
| `stat(k)` | `allocatedStat(k) + passiveBonus(k)`，不再根据等级自动加点。 |
| `checkAllocate(delta)` | 只接收四维非负整数增量，缺键为 0；返回 `{ok:true}` 或 `{ok:false,reason:'invalid'\|'overspend'}`。负数按 `invalid` 拒绝。 |
| `applyAllocate(delta)` | 复检后一次写入属性、扣点并 `save()`；额外失败原因 `save`，失败不改档。空增量不写档。 |
| `AttrPanel.snapshot()` | `open/unspent/remaining/rows/draft/pending/artUsed/check`，另含状态与位置；rows 含已分配值、含功法的当前值与草稿预览。 |
| `__xt.openAttrPanel()` / `attrSnapshot()` | 测试构建专用；开窗仍经过场景互斥检查，返回独立快照。正式构建沿用 leak-check 裁掉测试桥。 |

旧档缺 `allocatedStats` 时，只迁移一次：按 `AUTO_STATS[k] * (level-1)` 写入四维，未分配点置 0，保持既有属性与战力。迁移沿用 restore 的延迟保存标记；已有新字段的存档不会重新套种子。restore、导入验证与 exportSave 均覆盖新字段，损坏的本地字段规范化为合法非负整数，非法导入直接拒绝。

新角色四维初始为 0；每次实际升级（普通升级、突破及突破后溢出连升）只增加 `Number(GROWTH.perLevel.statPoints)||0` 个未分配点。每级点数及属性效果继续读成长表。`AUTO_STATS` 只用于旧档迁移。

P 开关加点窗；↑↓ 选属性、←→ 加减草稿，鼠标也可加减；回车或确认钮分两步提交。取消待确认时返回编辑，编辑时取消清空草稿；Esc、关闭钮或 P 关闭均丢弃草稿。C 保持跳跃。加点与对白、功法 K、丹炉 L、商店互斥，接入现有 modal 聚合；首领死亡的延迟对白出现前也会关闭加点窗、丢弃草稿。不新增功能开关。

窗体复用 preloadHud / preloadAlchemy 的 `ui_bestiary_*`、`ui_alchemy_list_row_*`、`ui_alchemy_btn_*` 可选资源，无需新增加载路径。每件缺图独立退回代码画，`artUsed` 记录 `art|code`；G17 关闭钮、G18 实体窗体图缺失（返回 200 HTML）均要求 `console.error=0/pageerror=0`。

已有属性名读取 `ui.rootBone/agility/spirit/insight`。本次不改共享 balance 或快照，新文案统一 `label(key, 中文兜底)`。待天机阁补齐同源 strings key：`ui.attr.title/remaining/planned/attribute/current/draft/value_hint/confirm_hint/ready/empty/cancel/confirm/keys/success/overspend/invalid/save_failed`（各后缀分别组成完整 key），共享表与快照需同步。
