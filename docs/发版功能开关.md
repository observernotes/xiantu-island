# 发版功能开关

集中定义在 `src/features.ts`，构建时读取本工程快照 `data/features.json`（主工程即 `game/data/features.json`）。
文件缺失、未填写的开关默认 `true`；开发分支行为不变，存档中的 flags 不覆盖发版配置。

| 开关名 | 设为 false 后 |
| --- | --- |
| `fiveSectClasses` | 隐藏非剑徒拜宗任务入口，已有职业与技能保留；剑徒入口照常。 |
| `sectDaily` | 隐藏宗门日常，暂停任务进度、交付和日界重置，存档任务保留。 |
| `sectRanks` | 隐藏职位晋升入口，已有职位与贡献保留。 |
| `sectShopLibrary` | 隐藏宗门货架、藏经阁兑换入口，普通商店照常。 |
| `sectDonations` | 隐藏宗门上交入口，背包与上交记录保留。 |
| `seclusion` | 闭关入口提示「暂未开放」，不扣贡献、不结算年份。 |
| `alchemyPhase1` | 关闭采集、丹炉和火候入口，已有材料、丹方及已付料炉次保留。 |
| `v05Maps` | 新地图传送门、渡船航线提示「暂未开放」；旧档可读并可返程。 |

release 前：先刷新快照，再在 `data/features.json` 写平铺 JSON 布尔值，例如 `{"sectDaily":false,"alchemyPhase1":false}`。
未通过执法堂第一级和关键流程清单的功能必须显式写 `false`；通过后才能改回 `true`。
将该文件随快照提交并合入 release 分支，再执行 `XT_DATA=snapshot npm run build`；配置在构建时冻结。
`npm run snapshot` 会保留已有 `data/features.json`，不会覆盖发版决定。
测试：`npm run build:test` 后执行 `npm run test:features`；端口由 `XT_TEST_PORT` 指定，默认 4312。
测试构建可调用 `window.__xt.setFlag('sectDaily', false)`；`getState().features` 查看有效值。
测试切换只在当前页面生效，跨地图保留、刷新恢复快照；正式构建没有 `window.__xt`。
