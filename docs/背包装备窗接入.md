# UI-7 背包与装备窗接入

`InventoryPanel` 替换 I 的文字背包，360×440、6×6 格，起点 (22,64)、间距 52，32px 图标放在格内 (+6,+6)。全部 / 装备 / 消耗 / 材料 / 其他按 `ITEMS.type` 分类，每页 36 种非零库存，翻页不限制实际背包容量。未知旧物品保留 id 和数量，缺图标显示名称前两字。数量含持有的临时物品，但手动穿戴只消耗永久库存。

`EquipPanel` 为 300×330，中间 120×150 inset 以角色名、境界和道袍名作精简预览；武器、道袍、鞋展示当前三槽，空槽用 `ui_alchemy_slot_empty`。属性两列、12 号字，只读 `Progress.atk/def/maxHp/maxMp/matk` 与 `currentMovePoints().speed`，没有另算公式。实际玩家外观继续由 `Player.syncAppearance()` / `Appearance.ts` 管理，狐裘、旧尺寸和缺图集回退规则保持原样。

| 接口 | 约定 |
| --- | --- |
| `EQUIP_SLOTS` / `EquipSlot` | 只读三槽 `weapon/robe/shoes`。 |
| `Progress.equipItem(id)` | 物品表存在、`type=equip` 且槽合法，永久背包至少一件；宗门与 `reqLevel ?? 1` 沿用 `gainEquip` 条件。允许主动换成更弱的装备，扣一件，旧装备回包。 |
| `Progress.unequipSlot(slot)` | 三槽有装备即可卸下，不重新检查等级/宗门，允许旧档未知装备返回背包。 |
| `EquipResult` | `{ok:true}` 或 `{ok:false,reason:'invalid'\|'missing'\|'sect'\|'level'\|'empty'\|'overflow'\|'save'}`。拒绝非法槽、缺货、临时库存和数量溢出。 |
| 保存与回滚 | 成功一次 `save()`；气血/灵力只裁至原 getter 的当前上限，不补满。失败恢复装备、库存、气血与灵力，窗内显示失败原因，可以重试。 |
| `InventoryPanel` | `open/close/toggle/isOpen/update/snapshot/artUsed`；操作入口 `setTab/setPage/select/activate`。快照含分类、页数、全部过滤行、选择、操作、状态、位置与资源使用。 |
| `EquipPanel` | 同上生命周期；`unequip(slot)` 即时卸下；快照含三槽、选择、派生属性、外观、状态、位置与资源使用。 |
| 场景回调 | 穿脱成功同步玩家外观、`player.maxHp/hp` 和功法窗。两窗关闭不撤回已成功的穿脱。 |
| 测试桥 | `__xt.openInventoryPanel()/inventorySnapshot()`、`openEquipPanel()/equipSnapshot()`；开窗经过同一场景门禁，快照独立拷贝。只在测试构建启用，正式 build 运行原 leak-check。 |

**需主程序过眼**：本次按 UI-6 薄接口方式补上穿脱事务；请复核 `equipItem/unequipSlot/changeEquip` 的库存搬运、保存回滚和上限裁切。没有新增存档字段、迁移版本或导入限制；没有修改属性公式、`appearance` getter 或 `gainEquip` 自动掉落逻辑。`test:equip` 覆盖旧档缺槽、导入、读档往返以及保存失败。

I 开关背包，E 开关装备；两窗互斥，按另一个键直接切换。背包方向键选物品，Tab / Shift+Tab 切分类，PageUp/PageDown 或 ‹/› 翻页，回车 / Z 或操作钮执行；装备方向键选槽，回车 / Z 或点击格子卸下。Esc、关闭钮及当前 I/E 关闭。穿脱可逆、即时保存，不设二次确认。

两窗纳入场景 modal 聚合；开窗取消采集、停止水平移动、隐藏旧 `invText`。对白、功法 K、丹炉 L、商店、加点 P、试炼 `blocksInput` 中 I/E 均禁止打开；背包/装备内 K/L/P 不抢占。场景程序入口实际打开加点、炼丹、商店或对白时先关闭两窗；首领死亡 600ms 延迟对白同样先收窗。`invText` 对象暂保留供旧调试代码引用，I 不再打开它，旧列表与浮动按钮可见路径已移除。

持有丹炉在「全部 / 其他」中选中后显示「使用丹炉」，调用原 `GameScene.openAlchemy(id)`，受 `alchemyPhase1` 门禁限制；入口失败保留背包与原因提示。持有 `five_sect_token` 且未入宗、无待办试炼时显示「五宗令」，调用原 `openSectToken()` 打开去向选择。成功切换目标 modal 时关闭背包。其他消耗品仍可从原快捷键使用，本窗只显示数量。

所有窗体/标题/关闭/inset 共用 `ui_bestiary_*`；按钮用炼丹按钮。九切片只经 `hudSpec/sliced` 读取 `slice/nineSlice`，不写死边距。背包 `ui_hud_slot` 改走现有 `loadOptionalImage`，缺图时快捷栏也沿用原代码画回退。各件独立回退并记录 `artUsed: art|code`，物品图标按 `item:<id>` 记录。G17 关闭 PNG、G18 窗体 PNG 缺失沿用 `optionalAssets` 的静默失败处理，保持 `console.error=0/pageerror=0`；关闭件代码回退有真实可点击 ×。
