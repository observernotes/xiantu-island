# 美术升级批 0 引擎接入

正式素材进 `art/sprites`、`art/tiles`，运行 `npm run sync`；工作稿与测试夹具不自动接入。
坐标/速度使用世界 1x 像素/像素每秒；帧画布与 bodySize 使用源素材像素。

E-1：每个 `<key>.anims.json` 独立读取（本体、狐裘、五套道袍均相同）：
```json
{"atlas":"player_sword_m","frameSize":192,"origin":[0.5,1],"bodySize":[52,116],"displayScale":0.5,"pixelArt":false,"anims":[]}
```
`frameSize` 可为正方形边长或 `[w,h]`；图集 JSON 的 sourceSize 必须与之匹配。
`anims` 沿旧动作/帧名/帧数/帧率填写，示例空数组仅省略展示。displayScale 缺省 1。
世界碰撞 = bodySize × displayScale；2x 主角仍 26×58，源框居中、底边贴画布底。
96×96 / 192×192 可逐 key 并存；换装保留帧序号、播放计时，抓绳保留缩放。
缺 frameSize 读 atlas 帧 sourceSize，缺 origin 用 [0.5,1]，缺 bodySize 沿旧碰撞框。
纸娃娃同帧换图与 NPC 名牌按显示高度，技能/受击/采集挂点仍从脚底按 1x 偏移。
BRIEF 插画沿旧线性过滤；pixelArt=true 可逐 key 开 nearest，2x 图集留透明边距防渗色。
无 displayScale 时旧 1x 行为不变；文件缺失不登记，换装回本体，本体缺图回旧占位。

E-2：选择 `art/tiles/bg_<area>.json`，area 对应现有 MAP_AREA（青云村是 qingyun）。
```json
{"layers":{"sky":{"texture":"bg_qingyun_sky","scrollFactor":[0,0],"yOffset":0,"tile":true},"far":{"texture":"bg_qingyun_far","scrollFactor":[0.2,0],"tile":true},"mid":{"texture":"bg_qingyun_mid","scrollFactor":[0.5,0],"tile":true},"near":{"texture":"bg_qingyun_near","scrollFactor":[0.85,1],"tile":false},"fg":{"texture":"bg_qingyun_fg","scrollFactor":[1.15,1],"yOffset":0,"tile":true,"alpha":0.9}}}
```
纹理默认读 `art/tiles/<texture>.png`；层可写 file 指定相对路径，sync 只加载存在文件。
数组 layers 也可用 key 标层名；兼容 scrollFactorX/Y（或 factorX/Y）、repeatX。
y 是底边世界坐标；缺 y 时纵系数 0 对屏底，否则对地图底，再加 yOffset。
平铺/非平铺宽度按实际地图宽；系数 >1 时补齐镜头行程；非平铺图按此宽度展示。
fg 固定 depth=20，所有美术配置 depth 不可覆盖引擎层级；提示/HUD/对话仍在上方。
无配置或所有配置纹理缺失，完整回旧天空+far+mid；部分缺层跳过，缺 sky 用旧天空。
旧回退的视口平铺/位置保持原样，以保证逐像素一致；新五层没有固定 1024 宽度。

E-3：`tiles_<area>.json` 可新增 `"variants":{"1":[16,17],"5":[18,19],"12":[20],"13":[21]}`。
数组为额外块，原块自动加入；候选数取数组长度，不写死，覆盖全部地块/边缘/梯绳/草。
也接受 Tiled properties 中的 variants（对象或 JSON 字符串）。
重排图集用 `tiles:[{"id":18,"role":"ground_fill","variant":0,"weight":1},...]`，同 role 多候选；
role 名沿旧 tiles JSON，0 号 variant 为基础，weight 缺省 1，可写 0 禁用；仅 role 不启用变体。
外部图集：`"5":{"tileset":"tiles_altar_fill_variants","frames":[0,1,2],"includeBase":true}`。
等权沿 UI-1 坐标哈希，异权按累积权重；无信息或无对应贴图退原块，碰撞布局完全不变。

| depth | 内容 |
|---|---|
| -10/-9/-8/-7 | sky/far/mid/near（旧三层保留原位置） |
| -1 | 地块、梯绳 |
| 3–8 / 10 / 11–12 | 道具/NPC/怪、主角、血条/技能 |
| 20 | fg 前景 |
| 30 / 40 / 50 | 交互提示/采集条/伤害字 |
| ≥100 / ≥150 | HUD / 对话框 |
