# 生活技能等级接入

炼器阁·主程序，2026-10-16。依据演武堂《20261015_生活技能等级曲线》全文，重点按第 4、5、8 节接入。`lifeSkillCurve` 在 `data/features.json` 显式为 `false`，缺省也关闭；`integrationState: pending` 仅表示配表交付状态。制符仍另受 `talismanCraft` 控制。

## 数据与配置错误

`data.ts` 经既有 `@xt/balance/life_skills.json` 加载；dev 默认共享目录，快照分支默认 `data/balance`，`XT_DATA=shared|snapshot` 规则不变。新表通过 `npm run snapshot` 引入，预检 artcheck/datalint 通过；刷新时顺带出现的 strings_zh/trials 变化已恢复为原快照，避免夹带无关内容，没有手改 JSON 数值。

`LifeSkills.ts` 校验 schemaVersion=1、三技能各 30 行连续级别、必需叶字段的类型/范围、配方真实引用/所属类型/重复、经验累计、满级哨兵、成功率/品质/产量参数与等级行的一致性。现有 11 方必须有显式映射且许可仍为 1。运行只消费 `levels`，参数只作校验，不能重复叠加。配置深拷贝后深冻结；坏表导出 `LIFE_SKILLS=null` 和带字段路径的 `LIFE_SKILL_ERRORS`，开启曲线的制作/学习/购买返回配置错误并拒绝消费，经验不增长。关闭曲线继续原规则。

## 炼丹

升级需求、30 级封顶、逐炉经验、成功率等级项、品质迁移和产量均读取新表，替代原规则中的等价项。基础率、炉/火加成、等级差惩罚、基础品质、正中火候品质奖励仍用原表。专项测试断言全部 30 级、6 丹方、所有炉/火组合及成功/失败经验与旧公式数值等价，未二次添加等级奖励。

每炉成功经验 `expSuccessPerRank × rank`，失败乘比例向下取整；只允许正式 `alchemy` 动作，rank0 无经验，满级不增长。先按开炉等级结算产出，再授经验；批量逐炉推进等级和本级余量。满级行的 0 只作视图哨兵，经验需求接口返回 Infinity，升级循环先判断满级。产量 `floor(outputCount × (1 + levels.outputBonusRate))`，当前加成为 0，无额外掷骰或隐藏产出。

显式旧方 `minSkillLevel` 优先，低级仍可强炼旧高阶丹方，继续受原等级差惩罚。未来未登记的新方只有合法真实配方及 recipeLevel 时才走 `futureRecipeRankGate`，缺阶数返回配置错误；无许可时不学习、不扣购方款、不开始制作。未补入现炼丹原本没有的境界门槛。

## 制符事务与迁移

新增 `talismanLevel/talismanExp`，旧档默认读 curve.initialLevel/initialExp；非法等级夹取 1～30，经验限非负有限整数，满级余量清零。有效旧炼丹等级和未满级余量保留。关闭曲线的新档不导出四个新增生活字段、不生成新经验标记；已获得的非默认生活数据继续保留，开关不写入存档。

正式制符成功率加对应等级行 successBonus（当前 0.001×(L−1)），仍走原宗门加成和上限。品质完全由完成度与宗门封顶决定，制符 qualityShift 必须为 0。完成度低于 minCompletion 的失败、研墨、试炼、放弃/中断及预检失败均无经验。

`commitResult` 在 `runSaveTransaction` 内同时写结果、经验和 `attempt.lifeSkillExpGranted=true`；保存失败整笔回滚，重试使用已缓存的判定，不重掷。`pendingOutput` 复制同一标记；归一化/待领取恢复保留 true，缺少冗余 pending 时从已定结果重建并复制标记。旧已定结果不追授经验，读档、领取、打开结果、再次恢复均不调用授经验。是否入包不影响已正式提交的一次经验。

## 炼器预留

新增 `forgingLevel/forgingExp`，与新制符字段使用同样的初始化/归一化/导出规则，提供只读状态。仅索引现表空 recipeRanks，没有打造入口或授经验接口，也不连接强化、附灵、分解。未知图纸不会回退为 rank1 或免费打造。v0.5 不做炼器玩法。

## 界面只读接口（3 行）

1. `Progress.lifeSkillView('alchemy'|'talisman'|'forging')`：level/exp/expToNext/maxLevel/maxed、enabled/available、configErrors；满级 expToNext=0。
2. `AlchemySystem.preview(recipeId, fire?, furnace?)`：rate、qualityRates、permitted/reason、outputCount、configErrors；`Progress.recipeSkillPermission(id)` 提供独立生活许可原因。
3. `TalismanSystem.preview(recipeId, completion?)`：successRate、qualityDistribution（指定完成度下的条件品质）、allowed/reason、outputCount、minSkillLevel。
