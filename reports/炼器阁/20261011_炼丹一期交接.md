## window.__xt 与人工验收

仅 `npm run build:test` 编入 `window.__xt`。运行 `npm run preview`，打开预览页，等游戏场景就绪后在浏览器控制台执行：

```js
const xt = window.__xt;
xt.setFlag('alchemyPhase1', true);
xt.setFlag('shops', true); // 买丹方时需要；正式快照 shops 仍为 false
await xt.loadSave({
  level: 12, exp: 0, stones: 20000,
  quests: { q_snake: { state: 'done', kills: {} } },
  inventory: { spirit_herb: 4, rabbit_fur: 1 },
  position: { mapId: 'qingyun_village', x: 1024, y: 640 }
});
await xt.teleport('qingyun_village', 1024, 640); // 孙郎中
xt.seed(42);
console.log(xt.getState().features, xt.exportSave());
```

1. 孙郎中按 Z，服务菜单选择「初识丹道」，真实推进对白接取；上述夹具把蛇胆任务设为已完成，若关闭 shops 会直接走入门对白；真实角色需先完成蛇胆任务。检查 `xt.exportSave().learnedRecipes` 有回春丹方。
2. 传送竹林作落点夹具，站到实际灵草点按住 Z。先松键确认不发物品，再完整读条采 1 草；检查冷却、头顶键帽、角色动作、y−88 读条。可以 `await xt.teleport('bamboo_forest')`；地图入口/采集行为仍用真实输入。
3. 备齐共 5 草/1 绒/10 石，回孙郎中 L 开公共炉，鼠标「炼制」，真实空格控火；另测「跳过」、×5（先备五份）。缺料、缺石各确认禁用；失败仍扣料/燃料、经验减半；成功品质/产物与经验入存档。
4. 开炉付料后刷新，继续原炉，核对扣料/燃料仅一次，成丹后 `pendingAlchemy=null`；交付入门后丹方各一次、青铜炉一次。回春丹按表每炉 5 颗，craft 记 5；交付消耗 3 草并奖励返 3 草。
5. 持有青铜炉后，真实 I 点击背包标题旁的使用入口，检查开窗且炉子数量不变。背包里有多种炉时选当前最高加成；新版完整背包窗口仍归 UI-7。
6. 用 `const save=xt.exportSave(); save.level=15; save.exp=0; save.stones=20000; await xt.loadSave(save)` 设置购买门槛夹具。孙郎中「学习丹方」买清心，筑基应灰显；升至 20 级后买筑基。检查余额、学方去重和刷新保存，已学方灰显。`reqLevel` 是购买限制，已学方可炼；丹方等级差影响成功率。
7. 执行 `xt.setFlag('alchemyPhase1', false)`：检查清单中的全部入口/指引/追踪隐藏，L 与采集不生效，丹方购买无入口；已付料炉与材料/任务仍在 `xt.exportSave()`。再开启可继续。`xt.getState().features` 看有效开关。
8. 截图/存档/错误证据可用 `xt.exportSave()`、`xt.events.drain()`；炼丹字段在 exportSave，getState 不含专用炼丹字段。页面刷新恢复快照开关，重新设置测试覆盖。`xt.clock.pause/advance` 仅控制绝对时间（包括采集再生），不会暂停火候/采集读条的 Phaser 帧。
